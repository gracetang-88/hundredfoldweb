# 文章标题

## 章节标题

你可以使用：
- 项目符号
- **粗体文字**
- *斜体文字*
- 链接：[链接文字](https://example.com)

### 小节

根据需要添加更多内容。

## 嵌入视频

如果你想嵌入 YouTube 视频，请在上面的 frontmatter 中添加 videoUrl。
视频 ID 是 YouTube URL 中 `watch?v=` 后面的部分。
例如：https://www.youtube.com/watch?v=dQw4w9WgXcQ
视频 ID 是：dQw4w9WgXcQ
所以嵌入 URL 是：https://www.youtube.com/embed/dQw4w9WgXcQ
