## Embedding Videos

If you want to embed a YouTube video, add the videoUrl in the frontmatter above.
The video ID is the part after `watch?v=` in the YouTube URL.
For example: https://www.youtube.com/watch?v=dQw4w9WgXcQ
The video ID would be: dQw4w9WgXcQ
So the embed URL is: https://www.youtube.com/embed/dQw4w9WgXcQ
